Poche signed browser-device gateway lab

This is a host-authoritative compatibility lab, not decentralized consensus. The browser holds a non-extractable session device key and signs typed actions. The gateway can read command and exact-recipient projection plaintext, delay/censor/reorder traffic, and unilaterally order this lab room. It cannot sign as the browser device or read a player-root key because neither secret is sent here.

Machine-readable trust disclosure

Enrollment is deliberately a lab invite shortcut. Production replicated membership uses the root-signed device certificates checked in phase 5; this page does not pretend its facilitator enrollment is that protocol. Gateway-custodied fallback is disabled: an unsupported browser is blocked conspicuously instead of silently uploading a key.
