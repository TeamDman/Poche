What we built. What we learned.

Poche is now more than a rules document: it is a typed game engine, four independent formal models, a multiplayer session protocol, viewer-correct rendering, native-network experiments, and a first reinforcement-learning pipeline. This page separates working pieces from experiments, and experiments from claims.

Architecture

One meaning, several consumers

Game rules, room rules, transport, presentation, and learning are deliberately separate. Network or UI code cannot silently become a second game engine, and training avoids text parsing and sockets.

01 · Command

Typed and signed

Versioned commands have canonical NDJSON for inspection and direct typed ingress for fast paths.

02 · Session

Default deny

SessionState owns membership, countdown, pause, chat, grants, and authorization reasons.

03 · Game

Rules stay pure

GameEnvironment owns chance, legal actions, transition, settlement, and terminal meaning.

04 · Consumers

Scoped outputs

Text, egui, HTML, Veilid, replay, and RL consume events or viewer-safe projections.

Experiment ledger

Outcomes, including failures

“Pass” means the named executable scenario worked. “Selected” means the result changed the architecture. “Bounded” and “empirical” are deliberately weaker labels than proof.

Browser Veilid over HTTP

Pass

A browser-only Veilid 0.5.7 node connected by insecure ws:// with no native companion, reaching public-ready with 28–31 peers.

Meaning: the WASM/browser architecture is viable in development, but HTTP cannot protect a real public card game.

Browser Veilid over HTTPS

Unsupported

From a real HTTPS origin, the tested public wss:// bootstrap reset before TLS and the node remained attaching with zero peers.

Decision: do not advertise direct Pages multiplayer and do not smuggle in a companion app as a hidden requirement.

Native Veilid protocol

Acceptance pass

Two native processes exercised DHT rendezvous, private routes, one-time invite redemption, signed commands/events, reconnect, chat, pause/resume, exact-recipient hand delivery, leave, and close.

Observed: 174 calls, 172 contiguous event frames, final revision 173. This proves the protocol scenario—not a packaged client or network availability theorem.

Datastar + Axum

Selected fallback

A self-hostable, host-colocated server drove the real typed authority and patched accessible semantic HTML for viewer-specific room state.

Tradeoff: it is easier for ordinary browsers, but less anonymous. The current named routes, static invites, and in-memory state are development scaffolding.

Shared egui renderer

Pass

The same projection model builds as a native Windows client and a Pages-hostable WASM replay. Privacy checks covered ungranted, granted, and revoked spectator views.

Decision: retain egui for native/static replay; use semantic HTML for the accessible live browser surface.

Direct Vulkan reference

Bounded pass

The ash-based latency reference demonstrated direct presentation control and low-level timing choices on native platforms.

Decision: useful for a future focused latency experiment, but too costly in portability and accessibility to become the first Poche renderer.

Spatial tabletop refinement

Checked slice

Native 3D and semantic HTML consume one exact-recipient scene fingerprint. Named and dragged play resolve to the same typed action and integer endpoint; Rust also renders a retained Alloy overlap witness.

Inspect: open the static spatial evidence page. Its receipt separates composed offline checks from a live network run.

Loopback multiplayer

Pass

A no-socket canonical-NDJSON scenario processed 178 inputs and all 13 deals, including abort/re-arm, pause by one player, resume by another, chat, grant/revoke, reconnect, completion, reset, and close.

Meaning: protocol semantics can be inspected and tested without relying on an external network.

Burn PPO learner

Empirical

CPU and WGPU ran the same 307-input, 60-action masked policy/value path. A short frozen-self-play PPO run replayed from a pinned manifest.

Outcome: score improved in the small held-out corpus, but only one of four 95% score-difference intervals excluded zero. This is a first experiment, not solved Poche.

Formal methods

Different tools, different questions

The non-Rust models are handwritten independent oracles. Agreement is checked only on declared common projections; none is treated as a syntax skin over Rust.

Rust + Weavy

Executes the complete game and exhaustively explores exact finite micro-scopes, with replayable counterexamples and controlled defects.

Alloy

Checks relational structure: ownership, partitions, membership, seat uniqueness, default deny, grant scope, and invalid witnesses—within printed bounds.

NuSMV

Checks temporal safety and liveness. It proves conditional termination under named fairness and deliberately finds infinite idle, paused, or missing-event traces without it.

Scryer Prolog

Answers forward and backward questions: legal successors, denied actions, predecessor causes, visibility, and grant/revoke explanations over productive finite modes.

Multiplayer semantics

The lifecycle now modeled

Room state composes around the game rather than polluting it. An application key, not a room code or transient transport identity, is the durable authorization principal.

  1. Create and inviteHost creates; a compact one-time/expiring code locates and redeems membership.
  2. Join and seatMembership and seat occupancy remain separate typed concepts.
  3. Ready and countdownAll seated players ready; any seated player may abort before authority expiry.
  4. Play and pauseOnly legal game actions advance; any player may pause and any player may resume.
  5. Chat and spectateBounded ephemeral chat; exact hand request, owner grant, and future-only revoke.
  6. Recover and finishStable-key reconnect, snapshot + tail, post-game, leave, reset, and absorbing close.

Reinforcement learning

Score-first, network-free

The first immutable contract, poche-2p-v1, exposes only the acting seat’s hand plus public history. Policies must select a masked legal action. Reward is zero between rounds and raw Poche score at settlement—no material proxy, terminal bonus, or hidden state feature.

What this does not claim

  • The host-authoritative process owns every hand. This is not mental poker, MPC, consensus, or protection from a cheating host.
  • Room codes are temporary invitations, not permanent bearer credentials. Transport node IDs and routes are not application authorization.
  • Spectator revocation stops future delivery; it cannot erase cards a person already saw.
  • A paused, partitioned, abandoned, or permanently hostless session may persist. Session termination needs explicit fairness assumptions.
  • Alloy results are bounded, NuSMV results describe its declared abstraction, Prolog completeness is query-mode specific, and sampled Rust tests are not exhaustive full-deck proof.
  • Training and evaluation measure policies on named finite corpora. They do not prove optimal play, rule consistency, or formal correctness.
